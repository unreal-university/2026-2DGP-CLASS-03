# LEC09 애니메이션 뷰어 검증 기록

검증일: 2026-10-05

- `python -m py_compile Labs/LEC09/sonic_animation_viewer.py` 통과.
- `sonic-sprite.png`의 소닉 동작 10개 행에서 `[11, 12, 6, 9, 6, 6, 6, 8, 8, 4]`개, 총 76개 프레임을 확인. 모든 자르기 좌표가 399×525 이미지 안에 있고 각 영역에 실제 그림이 있다.
- 76개 원본 프레임을 확대해 대조했고, 각 동작의 첫 프레임을 실제 pico2d 렌더러로 그려 잘림·행 혼입·4배 출력·화면 배치를 확인했다. 기본 격자는 숨겼다.
- 실제 pico2d 캔버스를 1200×800으로 열고 이미지 로딩, 반복 출력, 종료 이벤트를 확인했다.
- 시간 모의 검사에서 각 동작의 5회 반복, 마지막 프레임 1초 유지, 다음 동작 전환과 마지막 동작에서 첫 동작으로의 복귀를 확인했다. 전체 재생 시간은 48초다.
- 실제 시계로 전체 순환을 실행했다. 마지막 동작의 정지는 실행 시작 후 약 47.88초, 첫 동작 복귀는 약 48.88초에 관측됐다. 이 측정값에는 캔버스 초기화 약 0.88초가 포함된다.
- `feature/animation-viewer` 브랜치의 기준 커밋 `6316587` 이후 커밋 수와 한글 메시지를 확인했다.

실시간 화면의 모든 프레임을 사람이 직접 관찰한 검사는 별도로 필요하다. 렌더러 캡처와 시간 검사로 자르기 및 전환 규칙을 확인했다.

## 이동 기능 변경 후 확인 항목

이 절 위의 검증 결과는 이동 기능을 추가하기 전 코드에서 얻었다. 이동 기능 변경 후 자동 검사는 사용자 요청에 따라 실행하지 않았다. 실행하면서 다음을 확인한다.

1. 1·2·3·5·6·7·8·9행은 프레임 재생 중 위치도 계속 움직이고, 4·10행은 중앙에 머무른다.
2. 좌우 경계에서 그림이 잘리지 않고 이동 방향과 그림 방향이 함께 바뀐다.
3. 8행은 각 반복에서 올라갔다 내려오며 수평 이동도 계속된다.
4. 다섯 번째 반복 뒤 마지막 프레임과 위치가 1초 동안 고정되고, 다음 동작은 중앙에서 시작한다.
